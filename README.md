# Biblioteca de Aulas

Site estático para GitHub Pages.

## Como publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie todos os arquivos desta pasta para o repositório.
3. No GitHub, acesse `Settings > Pages`.
4. Em `Build and deployment`, selecione a branch principal, geralmente `main`, e a pasta raiz `/root`.
5. Salve e aguarde a publicação.

## Como usar

- Edite `index.html` para mudar a página inicial.
- Edite os arquivos dentro de `paginas/` para inserir os temas de cada disciplina.
- Use sempre o mesmo padrão de tema.
- Evite melhorar visual antes de registrar o conteúdo funcional.

## Regra de manutenção

Depois de cada aula, preencher apenas a seção: `Melhorias para próxima vez`.
